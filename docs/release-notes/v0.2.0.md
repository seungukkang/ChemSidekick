# v0.2.0 · 2026-11-13

A Raycast extension, and `csk --json` for scripts.

## Added

### Raycast extension (`apps/raycast/`)

- ChemSidekick command: pick a tool, fill in the form, see the result.
- Element command: search elements by symbol, name, or atomic number. Enter opens the card, ⌘T the periodic table.
- XYZ Viewer command: paste coordinates and get the 2D drawing and a rotating 3D view side by side.
- Stereoisomers command: type `stereo` and a SMILES. Press Enter on an isomer to see it rotate in 3D.
- ⌘E on any result to change the input and run again.
- The periodic table follows Raycast's light/dark mode.
- If `csk` can't be found or is out of date, the extension tells you how to fix it.

### `csk`

- `csk run <tool> --json` reads the tool's input as JSON from standard input.
- `csk list --json` lists every tool with its inputs.
- `csk gif --json` makes a rotating 3D GIF of a structure.
- `--no-record` runs a tool without saving it to the recent results.

### Tools

- `xyz` now draws a 2D structure, with bonds guessed from the coordinates. It may be wrong for metals, ions, radicals, and transition states, and shows a warning when it can't work out the bond orders.

## Changed

- `--json` output now wraps the result: `{"ok": true, "result": …}`, or `{"ok": false, "error": …}`. Errors are JSON too.
- Exit codes now tell you what went wrong: 1 bad input, 3 time or memory limit, 4 crash, 6 missing program.
- 2D drawings now have a white background with a red border, which is easier to see in dark mode.
- `csk ui` uses the same red accent.

## Known issues

- Bonds in the 3D views are drawn from distances only.
- Raycast can't show the interactive 3D viewer, so it opens in the browser.
- The XYZ Viewer can't fill in coordinates from the clipboard on its own. Use ⌘⇧V.
- v0.1.0's known issues for `stereo` and `element` still apply.
- Tested on macOS only.
