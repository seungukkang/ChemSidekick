# v0.1.0 · 2026-11-10

First release: three chemistry tools, available from the terminal (`csk`) and a local web interface (`csk ui`).

## Added

### Tools

- **`element` (REF-01)**: element card or periodic table.
  - Card: standard and abridged atomic weights, electron configuration, electronegativity, covalent radius, oxidation states, natural isotopes (or the longest-lived isotope).
  - Each value is checked against one primary source and two compilations (CIAAW, NIST, PubChem, NUBASE2020, IAEA, …). A check mark and reference numbers show how far each value was confirmed; values that could not be confirmed are marked.
  - Periodic table: number, symbol, name, and abridged atomic weight on each tile (mass number of the longest-lived isotope for elements without stable isotopes); click a tile to open its card.
- **`xyz` (STR-01)**: XYZ coordinates → formula, molecular weight with uncertainty, closest atom pair, and an interactive 3D view.
  - Reads standard and multi-frame XYZ, bare coordinate lines, atomic numbers, and Fortran-style exponents; unusual input is read with a warning.
  - Multi-frame files (trajectories, scans) play with a slider.
- **`stereo` (STR-02)**: all stereoisomers of a SMILES.
  - Descriptors R/S, pseudoasymmetric r/s, and E/Z, written with IUPAC locants, e.g. (2R,3s,4S).
  - Relations: pairs of enantiomers, diastereomers, and meso compounds (IUPAC definition).
  - One 2D drawing per isomer, and 3D structures (ETKDG + MMFF94) shown page by page, with buttons for locants and stereocenter marks.
  - Also accepts simple condensed formulas such as `CH3-CH(OH)-CH=CH-CH(OH)-CH3`.

### Interfaces

- **CLI**: `csk <tool>`, plus `csk list`, `csk search`, `csk recent`, `csk save`, `csk doctor`, and `--json` output.
- **Web interface** (`csk ui`): tool icons with category tabs and search, generated input forms, results with tables, drawings, and 3D views.
- The newest 50 results are kept automatically; `csk save` or the Save button keeps one permanently.
- Heavier tools run in a separate process with time and memory limits.

## Known issues

- `stereo` does not detect axial chirality (allenes, atropisomers, e.g. 1-ethylidene-4-methylcyclohexane), planar chirality, or helicity.
- IUPAC locants are available for open chains and single carbocyclic rings. Other structures (fused or heteroatom rings, stereocenters in a substituent) use atom numbers, written as `atom 3 S`.
- RDKit's CIP labeler leaves some ring stereocenters without a descriptor (e.g. cis,cis,trans-cyclohexane-1,3,5-triol); `stereo` shows a warning when this happens.
- In `element`, electron configurations (two sources available), electronegativity, covalent radius, and oxidation states are not yet confirmed by three references and are marked as such.
- The 3D viewer needs an internet connection (3Dmol.js is loaded from a CDN).
- Tested on macOS only.
