## How to write

- One file per version: `vX.Y.Z.md` (versions follow [SemVer](https://semver.org/)).
- Create the file at release time and add a row to the table above.
- List only user-visible changes. Internal planning and refactoring are not included.

### Template

```markdown
# vX.Y.Z · YYYY-MM-DD

One-line summary.

## Added
## Changed
## Fixed
## Known issues
```

Delete any section that has no entries.
